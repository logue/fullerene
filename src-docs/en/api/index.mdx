# API

## pluginFullerene()

```ts
function pluginFullerene(): RspressPlugin;
```

Returns an Rspress plugin that registers the theme stylesheet as a global style.

## stylesheetPath

```ts
const stylesheetPath: string;
```

The absolute path of the prebuilt stylesheet (`dist/style.css`). Use it when you need to pass the stylesheet to another tool.

## PLUGIN_NAME

```ts
const PLUGIN_NAME: 'fullerene';
```

The name the plugin reports to Rspress.

## fullerene/style.css

The prebuilt stylesheet as a package export. See [Getting started](/guide/start/getting-started#use-the-stylesheet-without-rspress).
